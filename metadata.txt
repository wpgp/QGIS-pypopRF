about=Create gridded population maps from census counts and aligned raster covariates. Calculations run in an isolated 64-bit Python 3.12 environment managed by the plugin. Initial engine setup downloads locked Python packages; activation never installs packages into QGIS. Census totals are verified separately for every zone. Model validation describes held-out census zones and does not establish pixel-level accuracy. This is an unpublished development build; qualification and remaining release gates are documented in the repository.
